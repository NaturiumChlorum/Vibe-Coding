# VibeHub

> 全员 Vibe Coding 效率工具平台

VibeHub 是一个面向业务人员与技术复核人员的纯前端效率工具管理平台。项目基于“人人都能用自然语言提出需求、AI 辅助生成代码、技术人员负责安全复核与交付”的实践理念，用统一入口沉淀工具资料、提示词资产、人工审核记录和可核验的效率数据。

平台不接入真实 AI API，不读取或扫描项目源代码，也不会把演示数据或人工勾选结果描述成真实企业成果。

## 技术栈

- React
- TypeScript
- Vite
- Tailwind CSS
- lucide-react
- Recharts
- localStorage 本地数据持久化

## 功能介绍

### 工作台

- 展示工具总数、已上线工具、提示词数量、待复核数量等概览。
- 汇总有效的工具成效记录和累计节省工时。
- 数据来自当前浏览器实际保存的记录，不使用虚构经营成果。

### 工具市场

- 提供日本数字化签证系统、GEO 品牌传播工具、项目签到系统、经营数据看板四个原项目案例。
- 案例仅作为资料管理，不表示已接入真实业务系统。
- 支持新增、编辑、查看、搜索、分类筛选、状态筛选和二次确认删除。
- 可填写实际访问网址；只有存在网址时才显示“打开工具”。

### 提示词库

- 内置 Excel 数据整理助手、活动签到管理系统、AI 信息提取工具、企业数据可视化看板四套完整模板。
- 支持搜索、分类筛选、查看完整内容、新增、编辑和二次确认删除。
- “使用此模板”会调用浏览器剪贴板 API 复制完整提示词，并反馈成功或失败状态。

### 代码复核

- 从工具市场选择工具并创建独立审核记录。
- 提供硬编码密钥、数据脱敏、访问权限、异常处理、操作日志、输入校验、核心测试、部署与回滚八项人工检查。
- 每项支持“通过 / 未通过 / 待检查”，并展示进度与状态统计。
- 支持保存审核人、审核日期与备注。
- 这是人工检查清单，不是自动静态代码扫描器。

### 数据看板

- 展示平台工具总数、已上线工具、提示词总数、待复核工具、累计节省工时和工具平均节省工时。
- 支持人工填写优化前耗时、优化后耗时、累计使用次数和统计备注。
- 自动计算：`累计节省工时 =（优化前耗时 - 优化后耗时）× 使用次数 ÷ 60`。
- 缺失值、非法数字、负数、非整数使用次数和优化后耗时大于优化前耗时的数据不会计入统计。
- 使用 Recharts 展示工具累计节省工时柱状图与工具分类分布饼图。
- 演示模式有明确标识，演示数据不会写入真实记录，也不会进入首页统计。

## 本地运行方法

### 环境要求

- Windows 10/11
- Node.js 18 或更高版本
- 推荐使用 pnpm；也可以使用 npm

### 使用 pnpm（推荐）

```powershell
corepack enable
pnpm install
pnpm run dev
```

浏览器访问终端显示的本地地址，通常为：

```text
http://127.0.0.1:5173/
```

生产构建：

```powershell
pnpm run build
```

### 使用 npm

如果本机已经正确安装并配置 Node.js/npm：

```powershell
npm install
npm run dev
npm run build
```

## 已实现功能

- 五个主要页面及桌面端、移动端导航。
- 工具资料完整 CRUD、搜索、筛选、详情和网址入口。
- 四个原项目案例及案例身份说明。
- 提示词完整 CRUD、搜索、筛选、详情和浏览器剪贴板复制。
- 四套可直接用于 AI 编程助手的完整默认提示词。
- 八项人工代码复核清单及独立工具审核记录。
- 工具成效录入、校验、计算、图表展示和首页联动。
- 明确隔离的演示数据模式。
- localStorage 自动保存，刷新页面后数据仍可恢复。
- 操作反馈、空状态、删除二次确认和响应式布局。

## 尚未实现的功能和局限

- 没有账号、登录、角色权限或多人协作能力。
- 没有后端数据库；数据仅保存在当前浏览器与当前访问域名中，清理浏览器数据后无法恢复。
- `localhost` 与 `127.0.0.1` 属于不同浏览器存储域，数据不会自动互通。
- 没有云端同步、导入导出、备份或跨设备迁移功能。
- 没有接入真实 AI API，平台不会自动生成代码或提示词执行结果。
- 代码复核是人工清单，不会读取仓库，也不具备自动漏洞扫描能力。
- 没有自动采集工具使用次数；所有成效数据均需人工填写并确认口径。
- 当前项目未配置单元测试、组件测试或端到端自动化测试脚本。
- 当前为单页前端应用，未配置生产环境部署与服务端路由。

## 数据与安全说明

VibeHub 当前只在浏览器本地存储数据。请勿在演示环境中录入密码、API 密钥、真实个人敏感信息或未经脱敏的企业数据。人工审核结果仅代表审核人员的记录，不构成安全认证。
